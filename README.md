# TDD – Calculadora de área de un rectángulo (Java 17 + JUnit 5)

Proyecto Maven para desarrollar el caso propuesto de TDD de forma incremental.

## Requisitos
- JDK 17 o superior
- Maven 3.x

## Ejecutar pruebas
```bash
mvn test
```

El historial Git conserva los estados **Red → Green → Refactor** para poder evidenciar cada ciclo con capturas reales.
