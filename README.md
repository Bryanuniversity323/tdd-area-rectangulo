# TDD – Calculadora de área de un rectángulo (Java 17 + JUnit 5)

Proyecto Maven basado en el caso propuesto de Calidad y Pruebas de Software. Incluye la solución final, pruebas JUnit 5, bitácora, reflexión y un historial Git real con estados **Red → Green → Refactor**.

## Requisitos
- JDK 17 o superior
- Maven 3.x

## Ejecutar el estado final
```bash
git switch main
mvn test
```

## Archivos principales
- `src/main/java/pe/edu/upn/area/Calculadora.java`
- `src/test/java/pe/edu/upn/area/CalculadoraTest.java`
- `BITACORA_Y_REFLEXION.md`
- `GUIA_CAPTURAS_TDD.md`
- `HISTORIAL_TDD.txt`

Consulta `GUIA_CAPTURAS_TDD.md` para obtener las capturas de cada ciclo usando los commits preparados.
